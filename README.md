The project focuses on analysing the Fremont Bridge Bicycle Counter dataset and building an interactive Python and Streamlit dashboard designed specifically for younger adults (18–35 years).

Project Overview
The Fremont Bridge Bicycle Counter dataset records hourly bicycle counts on the east (NB) and west (SB) pathways of the bridge.
This project uses Python to:

Clean and prepare the dataset

Explore patterns in bicycle usage

Build an interactive dashboard aimed at younger adults

Apply design principles, colour theory, and ethical visualization practices

Communicate insights clearly and visually

The dashboard is fully coded in Python and Streamlit using modern visualization libraries.

Dashboard Design (18–35 Audience)
The dashboard is intentionally designed for younger adults by incorporating:

Bright, modern colour palettes

Minimalist layout with intuitive navigation

Interactive elements (hover effects, filters, toggles)

Mobile‑friendly proportions

Clear, engaging charts that highlight trends and peak cycling hours

The design choices reflect current UI/UX trends popular among younger users.

Visualizations Included
The dashboard features:

Hourly bicycle traffic trends

East vs West pathway comparison

Daily and monthly usage patterns

Peak‑time detection

Interactive filters for date ranges and pathways

Each visualization follows best practices in:

Colour theory

Ethical data representation

Avoiding distortion or misleading scales

Accessibility (contrast, readability)

Data Preparation Workflow
The project includes a detailed data preparation pipeline:

Loading and parsing datetime fields

Handling missing values

Creating new time‑based features (hour, day, month)

Aggregating counts for trend analysis

Normalizing and structuring data for dashboard components

All preparation steps are justified in the accompanying report.
